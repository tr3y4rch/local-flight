Connection Mode

Pick the path you actually want. Community and VATSIM stay simple. Bring your own key is the only path that asks for personal API keys.

Community
Use the shared real-flight path through the relay. This install gets 50 schedule requests per 30 days, so it should be used with care.
Bring your own keys
Use your own AviationStack key for schedules and optionally your own RapidAPI ADS-B key for radar.
Virtual (VATSIM)
No real-data keys at all. Good for testing, simulator traffic, or the quickest first launch.
Community Choose this when you want real schedules without putting your own API key on the client. The shared allowance is 50 requests per 30 days per install.
Bring your own keys Choose this when you want direct subscriptions. AviationStack is required here. RapidAPI ADS-B remains optional.
Virtual traffic is selected. If you continue like this, Local Flight skips the real-data keys and connects straight to VATSIM.
