Support routes

Pick the lane that matches the problem.

Install or desktop help

For Windows, macOS, Raspberry Pi, LAN browser, Matrix, and setup questions, email home@beacontools.cc or open a GitHub issue when you have reproducible technical details.

Mobile testing

For TestFlight or Play Store testing interest, email home@beacontools.cc. The app is not publicly listed yet.

Standalone or relay issue

Check Network first. Standalone needs internet access and the hosted relay. It does not need your desktop or Pi server online.

Privacy or diagnostics request

Use privacy@beacontools.cc for privacy questions, diagnostics questions, retention/deletion requests, or data-request follow-up.

Safety note

Local Flight is not a certified aviation tool. Do not use Beacon Tools pages, apps, relay data, screenshots, or diagnostics for real-world navigation, dispatch, operational control, flight planning, or safety decisions.
