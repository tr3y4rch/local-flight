Ways to run it

Start with where the board should appear.

The same Local Flight install can drive a desktop window, a LAN browser screen, a Raspberry Pi kiosk, a phone app, or an LED matrix board.

Desktop

Use the packaged Windows or macOS app for the main flight board, local server, browser access, phone pairing, and LED matrix setup from one install.

Raspberry Pi

Run a small always-on display box as a headless server, HDMI kiosk, or browser kiosk for a dedicated board screen.

Mobile

The mobile app supports Companion for a paired desktop/Pi server, encrypted Remote Companion fallback away from LAN, and Standalone for a simpler phone-only board through the shared Beacon Tools relay. Version 0.5.1 is in TestFlight and Google Play testing.

Mobile details
What it can show

A practical board for arrivals, departures, and nearby traffic.

  • Guided setup for the shared Local Flight relay, your own aviation data keys, or VATSIM-only virtual traffic.
  • Airport-style departure and arrival boards with local time, weather, gates and status when available, codeshares, pinned flights, and several visual styles.
  • A radar view for real or virtual nearby traffic, with weather context, range controls, runway/map detail, and aircraft information.
  • VATSIM display mode for virtual-network boards, focused on callsigns, aircraft, routes, altitude, speed, and source freshness while avoiding pilot/controller personal identifiers.
  • History pages for recent movements, board patterns, filters, and local records kept on your own machine.
  • Phone pairing, LED matrix preview, generated matrix display files, local logs, settings, and consent-based diagnostics.

LED matrix

Preview and generate display files for Interstate 75 W / HUB75 LED matrix panels.

Shared relay

Shared data without every user managing aviation data keys.

Local Flight can use your own data keys, VATSIM-only virtual traffic, or the shared Beacon Tools relay.

Public relay URL

https://relay.beacontools.cc

What it does

The relay protects shared data keys, reuses cached airport boards, applies fair-use limits, and keeps personal display setups easier to start.

Network page

The relay is explained in plain language at beacontools.cc/network.

Privacy

Local first by default.

No accounts, no advertising SDKs, no data brokers, and no cross-app/site tracking.

Local data

Settings, API keys, board snapshots, history, logs, mobile appearance, and LED matrix settings stay local unless you choose a relay-backed feature or send a report.

Policy

The public privacy policy is at beacontools.cc/privacy. Privacy controls and data deletion guidance live at beacontools.cc/privacy/choices.

Not for professional or safety-critical aviation use

Local Flight is an informational display tool only. Data may be delayed, incomplete, cached, wrong, or unavailable. Do not use it for navigation, dispatch, operational control, flight planning, professional aviation work, or safety decisions. Always use official aviation sources and certified systems for real-world operations.
