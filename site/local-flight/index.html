Local Flight by Beacon Tools

Local-first flight boards for screens you own.

Local Flight is a self-hosted Flight Information Display System for Windows, macOS, Raspberry Pi, LAN browsers, mobile devices, radar/history dashboards, and HUB75 LED matrix panels.

Download releases Source on GitHub Privacy

Current beta target: 0.2.7. Flight, radar, weather, and surface data are informational display aids only and are not for navigation, dispatch, operational control, or safety decisions.

Install

Desktop

Use the packaged Windows or macOS app for the native Qt shell, local server, browser access, mobile pairing, and Matrix support from one install.

Raspberry Pi

Run as a headless server, native Qt HDMI kiosk, or Chromium kiosk. The Pi source bundle is made for small always-on display boxes.

Mobile

The Expo mobile app supports LAN Companion mode for a paired server and Standalone mode through the hosted Beacon Tools relay. iOS is the primary validation path; Android local development builds are supported.

What It Does

  • Guided setup for Local Flight Relay, bring-your-own provider keys, or VATSIM-only virtual traffic.
  • Real-world schedule boards using cached shared snapshots, AeroDataBox primary schedule data, AviationStack sparse fill/fallback compatibility, and stale-safe serving when live providers are slow or capped.
  • Passenger-style FIDS boards with airport-local time, city/country headers, status and gate chips, codeshare grouping, pinned flights, and four native board styles: Classic, PAX, VATSIM, and Nerd.
  • VATSIM display mode with callsign-first rows, filed plan, aircraft, altitude/speed, XPDR, source freshness, and suppression of pilot/controller personal identifiers.
  • Radar with real or virtual traffic, METAR weather, range controls, runway/surface/map/terrain context, and richer aircraft/status detail.
  • Deduped History analytics, Matrix preview/config/script generation, local logs, local settings, and consent-based diagnostics.

Display Modes

  • Native desktop shell for Windows and macOS, with Classic, PAX, VATSIM, and Nerd FIDS styles.
  • LAN browser UI for remote screens, tablets, headless installs, and compact Raspberry Pi layouts.
  • Mobile LAN Companion and Standalone modes for phone-sized board, radar, history, and reporting workflows.
  • Matrix preview and generated MicroPython client for Interstate 75 W / HUB75 panels.

Relay

Local Flight can run with your own provider keys, VATSIM-only virtual data, or the hosted Beacon Tools relay. The relay exists to protect provider keys, cache shared airport snapshots, and keep the hobbyist path usable without every install needing paid API credentials.

Privacy

Local Flight has no accounts, no advertising SDKs, no data brokers, and no cross-app/site tracking. Config, API keys, snapshots, history, logs, mobile appearance, and Matrix settings stay local unless you choose a relay-backed feature or send a report.
