Beacon Tools Network

How the shared relay helps Local Flight.

The optional Beacon Tools relay shares cached airport data, supports mobile Standalone, and routes encrypted Remote Companion messages without asking users to manage shared aviation keys or open inbound router ports.

Public relay: relay.beacontools.cc Shared cached boards Safety-first refresh limits

Public relay URL

https://relay.beacontools.cc
Local Flight can use this relay for activation, shared airport boards, radar/weather helpers, Remote Companion encrypted routing, phone app data, and reports you choose to send.

What stays private

The public relay only exposes the paths normal apps need. Credentials, maintenance tools, monitoring, and control panels are not part of the public website or end-user app flow.

What the relay does

Shared data with careful limits.

  • Reuses cached airport boards so multiple personal installs can watch the same airport without each one making separate upstream requests.
  • Keeps refreshes intentionally modest to protect shared limits and keep the community path sustainable.
  • Routes encrypted Remote Companion messages for explicitly paired phones when they cannot reach the host on LAN. The host must be online, and the relay cannot read the Companion request or response.
  • Lets mobile Standalone work without your desktop app or Raspberry Pi being online.
  • Can forward reports only when you choose to send them, while keeping shared data keys and maintenance details out of the app.
Connection help

Start with the path you are using.

  1. LAN Companion: keep the phone and host on the same trusted network, confirm Local Flight is running, and pair with the LAN IP/fingerprint-bound QR from Settings.
  2. Remote Companion: the host must remain online and relay-linked, and the phone's remote grant must still be active. Revoke and pair again from LAN if the grant was removed.
  3. Standalone: check the phone's internet access and try again after a few minutes. Cached boards may be served during upstream problems, and mobile radar refresh/range remains intentionally limited.
  4. If the problem continues, use Support and include the app mode, airport, approximate time, connection state, and diagnostics choice.

Not for professional or safety-critical aviation use

Relay responses and cached board data are informational display aids only. They may be delayed, incomplete, cached, wrong, unavailable, or intentionally stale. Do not use them for navigation, dispatch, operational control, flight planning, professional aviation work, or safety decisions.
