Beacon Tools

Small tools for local-first flight displays.

Beacon Tools is the dev studio home for Local Flight, a self-hosted flight information display system for desktops, Raspberry Pi, LAN browsers, mobile devices, radar/history dashboards, and LED matrix panels.
