One local server, several display surfaces, and a privacy-minded setup path for real or virtual flight boards.

Local Flight runs as a native desktop app, Pi server, LAN browser board, mobile companion or standalone board, and Matrix display feed. The next notes focus on LAN/browser parity and mobile pairing polish.

Safety note

Local Flight and Beacon Tools relay data are informational display aids. Do not use them for navigation, dispatch, operational control, flight planning, or safety decisions.
