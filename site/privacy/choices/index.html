Diagnostics

You decide whether automatic reports are sent.

Off

No automatic crash diagnostics. Manual reports still only send if you submit them.

Automatic reports

Automatic reports with logs

The stronger option can also include a cleaned excerpt from the most recent text log.

Manual app reports send only when you press Send. Manual app reports and enabled automatic diagnostics are cleaned on your device. Website bug reports pass through Beacon Tools, which limits uploads and cleans text before all three report types reach the developer's Linear report inbox. See Linear's privacy policy.

Local data

Use the app first; use file removal only for a full erase.

  1. Run setup again: use Reset Setup in Local Flight Settings. This keeps the installation identity and shared-service link so you can change setup without appearing as a new installation.
  2. Remove a remote phone: revoke it in the host's Settings before choosing Forget on the phone. Forgetting it only on the phone does not cancel the host's remote-access permission.
  3. Reset the mobile app: use the in-app reset to choose Companion or Standalone again. For a complete mobile erase, revoke Remote Companion first and then remove the app from the phone.
  4. Completely erase desktop or Raspberry Pi data: stop Local Flight, then remove ~/.localflight/ and ~/.localflight_identity.json. This advanced step removes both normal app data and its reset-safe identity anchor, so the next launch is treated as a new installation.
  5. Completely erase Linux server data: remove the server package first, then explicitly delete /var/lib/localflight and /etc/localflight. Normal package removal preserves these folders so an upgrade or reinstall does not erase your setup.
  6. Personal aviation keys: these stay in your Local Flight installation. A complete local erase removes Local Flight's saved copy.

Shared-service records

Online features may create a random installation identifier, usage counts, broad app/device details, encrypted-message routing details, last-connected times, and short-lived shared data. These records run and protect the service without creating a Local Flight account.

What is not intended

Beacon Tools does not intend to store raw IP addresses, names or emails from normal app use, personal aviation keys, readable Remote Companion messages, local movement history, Standalone history, full logs, screenshots, recordings, or account profiles.
