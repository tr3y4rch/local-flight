Privacy choices

Control what leaves your device.

This page is the short checklist for diagnostics, local data removal, mobile resets, and relay data questions. The full policy remains at beacontools.cc/privacy.

Open contact form Full privacy policy
Diagnostics

Reports are consent-based.

Off

No automatic crash diagnostics. Manual reports still only send if you submit them.

Auto

Automatic crash reports can send sanitized technical context when the app's diagnostics setting allows it.

Auto with logs

Automatic reports can include a sanitized recent log excerpt when that stronger diagnostics option is enabled.

Manual reports, website bug reports, and enabled automatic diagnostics are sanitized, forwarded through the Beacon Tools relay, and filed into Linear for developer triage. Website log uploads are accepted only as capped text excerpts. See Linear's privacy policy.

Local data

Delete local data on your own devices.

  1. Desktop or Raspberry Pi: stop Local Flight, then remove ~/.localflight/ to wipe local config, snapshots, history, logs, setup state, and local request logs.
  2. Mobile: use the app's reset flows where available, or remove the app to clear its local setup, selected airport, appearance, pinned flight, diagnostics choice, and local standalone history.
  3. Bring-your-own provider keys are local to your install. Removing local app data removes Local Flight's stored copy.

Relay records

Relay-backed features may create technical records such as random install UUIDs, hashed install fingerprints, token prefixes, usage counters, last-seen timestamps, short-lived airport interest rows, shared cache entries, and coarse app/platform profile fields.

What is not intended

The relay is not intended to store raw IP addresses, readable personal identifiers, personal provider keys from your install, local flight history, phone standalone history, full logs, screenshots, recordings, or account data.

Requests

Ask through the privacy contact.

Local Flight does not require an account or email address. If you use a Beacon Tools website contact form, your optional reply email and message pass through the relay to the support mailbox so Beacon Tools can reply.
